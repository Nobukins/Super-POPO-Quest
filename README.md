# Super POPO Quest ～ポポの だいぼうけん～

ピンクのひとつ目うちゅうじん「ポポ」が、まりゅう ドラグザードに いどむ **スーファミ風 RPG**。
[Super POPO Land](https://github.com/Nobukins/Super-POPO-Land)・[Super POPO Racing](https://github.com/Nobukins/Super-POPO-Racing) に つづく、スーパーポポ シリーズの しゅうたいせいです。
ブラウザだけで動き、ビルドやインストールは不要です。

## おはなし

ある夜、ユウタの部屋で ながれぼしを見た ポポ。アンテナが ビリビリひかって——気づくと そこは、
1000年の ねむりから まりゅうが めざめようとしている 剣と魔法の せかい「ステラード」だった。

ひとつ目に アンテナ…その すがたは、むかし まりゅうを ふういんした **でんせつの ゆうしゃ** そっくり！
こわれた UFO を なおして 地球へ かえるため、そして この せかいを まもるため、
3つの ほうぎょく（みどり・あか・あお）を あつめる たびが はじまる。

## なかま

| キャラ | しょくぎょう | とくちょう |
| --- | --- | --- |
| **ポポ** | ゆうしゃ | くちぐせは「〜ポ」。ひとつ目から ビーム、アンテナから かみなり。かいふくも できる |
| **ユウタ** | ちきゅうっこ | ポポの しんゆう（Racing から）。すばやく、パチンコ・ホームラン・おうえん。どうぐの かいふく量 1.5 倍 |
| **メル** | まほうつかい | ハッパむらの みならい。ほのお・こおり・ねむり・かいふく、さいごは「ドッカーン」 |
| **ガンテツ** | ちからもち | こうざんの さんぞくの おやぶん。こわい顔で こどもと ねこに よわい。「かばう」「ちからため」 |

ほかにも、ハッパむらの ポロじい、ランドールおう、こおりの まじょ フブキーナ、りゅうきし ガルム、
そして 地球から いっしょに とばされてきた **さかなやの うおまさ**（Racing の あの おじさん）が 旅を いろどります。

## モンスター

モンスターは すべて コードで 描いた オリジナル（ボスを ふくめて 約 50 しゅるい）。
まるっこくて ちょっと なまいき、でも おこると こわい —— を目標に デザインしています。

- **シリーズの なかま**: グミ・パタ・カラ・トゲ（Land から）、バナナざる（Racing の おさる）、そして **キングトゲ** が パワーアップして ふっかつ
- **ボス**: キングトゲ → ガンテツ → くろがねゴーレム → こおりの まじょ フブキーナ → りゅうきし ガルム → まりゅう ドラグザード（2 段階）
- メニューの「**ずかん**」で、であった モンスターの 絵・せつめい・よわい ぞくせいを 見られます

## あそびかた

| 操作 | キーボード | タッチ | ゲームパッド |
| --- | --- | --- | --- |
| あるく・カーソル | `←` `↑` `→` `↓` | 十字キー | 十字キー / スティック |
| はなす・しらべる・けってい（A） | `Z` / `Space` / `Enter` | A | A / B |
| メニュー・キャンセル（B） | `X` / `Esc` / `Shift` | B | X / Y |
| メニュー | `C` | ≡ | START |
| 音のオンオフ | `M` | 右上のボタン | – |

- **せんとう**: よこから見る ターン制。「たたかう / わざ・まほう / どうぐ / ぼうぎょ / にげる」。
  ぞくせい（ほのお・こおり・かみなり・ひかり・やみ）の じゃくてんを つくと「こうかは ばつぐんだ！」
- **やどや** で ぜんかいふく。**きろく**（セーブ）は メニュー・やどや・きょうかい・ダンジョンの かいふくの ゆか で。ぼうけんのしょは 3 つ
- **ふるさとのはね** で、いちど おとずれた まちへ もどれる
- 3 つの ほうぎょくが そろうと UFO が なおり、**モード7 風の 3D で そらを とべる**（A で ちゃくりく）

## 起動方法

`index.html` をブラウザで開くだけで遊べます（`file://` のままで動作します）。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### オンライン公開（GitHub Pages）

`.github/workflows/pages.yml` が入っているので、`main` ブランチに push すると自動で公開されます。
初回だけ **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

公開先: `https://<ユーザー名>.github.io/Super-POPO-Quest/`

### 1 ファイル版

```bash
python3 tools/build_single.py   # → dist/super-popo-quest.html
```

## ファイル構成

```
index.html          画面・タッチボタン・あそびかた
style.css           見た目
js/sprites.js       ポポのドット絵（シリーズ共通。tools/make_sprites.py で生成）
js/gfx.js           ドット絵の道具箱（自動の影つけ・ふちどり・ウインドウ・文字）
js/monsters.js      モンスターのドット絵（すべてコード）
js/chars.js         なかま・NPC のドット絵（フィールド用 4 方向 / バトル用ポーズ）
js/tiles.js         マップチップとバトル背景
js/audio.js         効果音と BGM（WebAudio のチップチューン + エコー、すべてオリジナル曲）
js/input.js         キーボード / タッチ / ゲームパッド入力
js/data.js          なかま・わざ・どうぐ・そうび・モンスター・エンカウント表
js/world.js         ワールドマップ（tools/gen_world.py で生成）
js/maps.js          町・ダンジョンのマップと NPC・宝箱の配置
js/engine.js        ループ・コルーチン（イベント）・ウインドウ・セーブ
js/field.js         フィールド（移動・会話・エンカウント・UFO のモード7）
js/battle.js        バトル（コマンド・ダメージ計算・演出・ボスの AI）
js/menu.js          メニュー・やどや・おみせ
js/events.js        ストーリー（プロローグ〜エンディング）
js/main.js          タイトル・エンドロール・起動
tools/              ワールド生成・マップ検査・プレビュー・1 ファイル版ビルド
```

## 開発用ツール

```bash
python3 tools/gen_world.py     # ワールドマップを作り直す (js/world.js)
node tools/check_maps.js       # 全マップの検査（行の長さ・ワープ先・宝箱/NPC の到達可能性）
```

- `tools/preview_monsters.html` … 全モンスターを一覧表示（`?only=kingtoge,golem` で しぼりこみ）
- `tools/preview_chars.html` / `tools/preview_tiles.html` … キャラ・タイル・バトル背景の一覧
- `index.html?notitle` でタイトルを出さずに起動し、ブラウザのコンソールから `PopoQuest.warp("castle", 14, 8)` などで 移動・テストできます
